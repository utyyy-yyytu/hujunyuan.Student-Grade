# 学生成绩管理系统 使用说明书

## 1. 系统简介
学生成绩管理系统提供学生成绩的在线查询与管理功能，支持学生、管理员两种角色。

## 2. 系统要求
- 浏览器：Chrome / Edge / Firefox 最新版本
- 网络：能访问部署服务器地址

## 3. 快速入门

### 3.1 注册
1. 打开系统首页，点击“注册”
2. 输入用户名和密码，点击注册
3. 提示注册成功后，前往登录

### 3.2 登录
1. 输入已注册的用户名和密码
2. 点击登录
3. 成功后进入主界面

### 3.3 查询成绩（学生）
1. 登录后自动跳转到个人成绩页面
2. 可按学期筛选成绩

### 3.4 管理成绩（管理员）
1. 使用管理员账号登录
2. 在成绩管理界面可录入、修改、删除成绩

## 4. 常见问题
- **Q：忘记密码怎么办？**  
  A：当前版本请联系管理员重置。
