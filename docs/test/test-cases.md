# 学生成绩管理系统 测试用例

## 1. 用户模块

### 1.1 注册功能
| 用例编号 | 测试项 | 输入 | 预期结果 |
|----------|--------|------|----------|
| TC-01 | 正常注册 | 新用户名+密码 | 返回201，提示注册成功 |
| TC-02 | 重复注册 | 已存在用户名 | 返回400，提示用户名已存在 |
| TC-03 | 密码为空 | 用户名，密码为空 | 返回400，提示密码不能为空 |

### 1.2 登录功能
| 用例编号 | 测试项 | 输入 | 预期结果 |
|----------|--------|------|----------|
| TC-04 | 正确登录 | 正确用户名+密码 | 返回200，登录成功 |
| TC-05 | 错误密码 | 正确用户名+错误密码 | 返回401，认证失败 |
| TC-06 | 不存在用户 | 不存在用户名 | 返回401，认证失败 |

## 2. 成绩模块

### 2.1 查询成绩
| 用例编号 | 测试项 | 输入 | 预期结果 |
|----------|--------|------|----------|
| TC-07 | 学生查成绩 | 已登录学生 | 返回成绩列表 |
| TC-08 | 未登录查询 | 未登录 | 返回401，跳转登录 |

### 2.2 录入成绩（管理员）
| 用例编号 | 测试项 | 输入 | 预期结果 |
|----------|--------|------|----------|
| TC-09 | 管理员录入 | 学生ID+课程ID+分数 | 返回201，录入成功 |
| TC-10 | 学生越权录入 | 学生账号 | 返回403，权限不足 |
