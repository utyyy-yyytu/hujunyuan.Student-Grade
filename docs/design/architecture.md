# 学生成绩管理系统 架构设计文档

## 1. 系统架构概览
本系统采用 B/S 架构（浏览器/服务器），基于 Python Flask 框架开发。
用户通过浏览器访问系统，后端处理业务逻辑并返回 HTML 页面。

## 2. 技术栈
| 层级 | 技术 |
|------|------|
| 后端框架 | Python 3.12 + Flask |
| 数据库 | SQLite（开发）/ MySQL（生产） |
| 前端 | HTML + CSS + JavaScript（Jinja2 模板） |
| 版本控制 | Git + GitHub |

## 3. 系统分层架构
- **表现层**：HTML 模板，负责页面展示和用户交互
- **业务逻辑层**：Flask 路由 + Python 模块，处理请求/响应
- **数据访问层**：SQLAlchemy ORM，负责数据库操作
- **数据层**：SQLite/MySQL 数据库

## 4. 模块划分
### 4.1 用户模块
- 注册：学生填写用户名、密码创建账号
- 登录：验证身份，创建会话
- 角色：学生、管理员

### 4.2 成绩模块
- 管理员：录入、修改、删除成绩
- 学生：查询个人成绩，按学期筛选

### 4.3 课程模块
- 管理员：管理课程信息
